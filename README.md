# 🎮 Color Play Game

A browser-based Color Play Game built using HTML, CSS, and JavaScript.

## 🚀 Features

- Random color sequence generation
- Increasing difficulty with each level
- User sequence validation
- Flash animations
- Game over detection
- Score/level tracking
- Restart using keyboard

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎯 How to Play

1. Press any key to start the game.
2. Watch the color that flashes.
3. Click the same color.
4. In every new level, remember the previous sequence and click the colors in the correct order.
5. One wrong click ends the game.
